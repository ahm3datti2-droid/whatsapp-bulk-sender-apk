# مرسل واتساب الجماعي — WhatsApp Bulk Sender (APK)

تطبيق أندرويد بسيط لإرسال رسائل واتساب (عروض وتسويق) لعملاء من ملف إكسل / CSV، من رقم المستخدم الشخصي.

## كيف يعمل؟

- التطبيق WebView يعرض صفحة HTML واحدة (`app/src/main/assets/index.html`) — كل البيانات محفوظة على الجهاز (localStorage).
- استيراد العملاء من CSV أو XLSX أو لصق من إكسل، تطبيع الأرقام المصرية، وإزالة المكرر.
- 3 قوالب عروض جاهزة + محرر رسالة فيه `{الاسم}` + معاينة.
- طابور إرسال: كل ضغطة بتفتح واتساب الرسمي (wa.me) والرسالة جاهزة باسم العميل، والمستخدم هو اللي يدوس إرسال.

## إضافة رقم رسمي وتوثيقه (قسم 5️⃣ في التطبيق)

- اكتب رقم المرسل بالصيغة الدولية (+20...) ودوس «إضافة الرقم».
- «اطلب كود التحقق»: لو التوكن الرسمي متعبّي، الكود بيتطلب من واتساب الرسمي عبر Cloud API (`request_code`)؛ ولو مش متعبّي، التطبيق بيفتح WhatsApp Manager الرسمي عشان تطلب الكود من هناك بنفسك.
- دخّل الكود الـ 6 أرقام ودوس «تحقق»: مع التوكن بيتم التحقق عبر Cloud API (`verify_code`)، ومن غير التوكن لازم تأكيد صريح إن الكود هو اللي وصلك من واتساب الرسمي.
- الرقم الموثّق بيتسجّل «موثّق رسمياً ✅» وبيتحفظ محلياً وبيظهر كرقم المرسل في كل حملة. الرقم غير الموثّق مينفعش يتبعت منه بالوضع الرسمي — الوضع اليدوي (wa.me) بيفضل متاح.

## وضع واتساب بيزنس الرسمي (Cloud API) — اختياري

من داخل التطبيق (قسم 4️⃣) تقدر تفعّل الإرسال الرسمي عبر WhatsApp Cloud API:
- حقول: Phone Number ID + WhatsApp Business Account ID + Access Token + اسم الـ Template المعتمد — بتتخزن على جهازك بس (localStorage)، ومفيش أي توكن في الكود.
- لما يكون مفعّل، زر الإرسال بيبعت أوتوماتيك عبر `POST https://graph.facebook.com/v20.0/<Phone Number ID>/messages` برسالة Template بالعربي (ar) فيها اسم العميل مكان `{{1}}`.
- **مهم:** الرقم المسجّل في الـ Cloud API مبيشتغلش في نفس الوقت على تطبيق واتساب الموبايل، ورسايل العروض لازم تكون Template معتمد من Meta، والعميل لازم يكون موافق يستلمها.

## ⚠️ تحذير مهم

- **مفيش إرسال تلقائي في الخلفية.** الإرسال يدوي بضغطة لكل عميل من واتساب الرسمي.
- استنى **10–20 ثانية** بين كل رسالة، وحد أقصى **80–100 عميل/يوم** للرقم الشخصي لتقليل خطر حظر الرقم.

## البناء

يتم البناء تلقائياً عبر GitHub Actions (`.github/workflows/build-apk.yml`) عند كل push على `main` — ينزل ملف APK من قسم Artifacts في صفحة الـ run.
