4️⃣ وضع واتساب بيزنس الرسمي (Cloud API) — اختياري

⚠️ اقرأ ده قبل ما تفعّل الوضع الرسمي:
• الرقم اللي بتسجّله في WhatsApp Cloud API مبيشتغلش في نفس الوقت على تطبيق واتساب الموبايل — الرقم بيكون مخصص للـ API بس، ومش هتقدر تستقبل وتبعت منه من تطبيق واتساب العادي.
• رسايل العروض والتسويق لازم تكون Template معتمد من Meta — مينفعش تبعت نص حر كعرض. النص الحر مسموح بس خلال 24 ساعة بعد ما العميل يرد عليك.
• لازم العميل يكون موافق يستلم رسايل العروض منك — إرسال لحد مش موافق ممكن يعرّض الرقم للحظر من Meta.
• بياناتك هنا بتتخزن على جهازك بس (localStorage) ومبتتبعتش لأي حد غير سيرفرات Meta الرسمية وقت الإرسال.

الوضع الحالي: يدوي — كل ضغطة بتفتح واتساب الرسمي والرسالة جاهزة، وإنت اللي بتدوس إرسال.

الإرسال الرسمي بيتم عبر: POST https://graph.facebook.com/v20.0/<Phone Number ID>/messages — رسالة Template بالعربي (ar). لو القالب مش معتمد أو التوكن غلط، الإرسال هيفشل وهتظهرلك رسالة الخطأ من Meta.

5️⃣ إضافة رقم رسمي وتوثيقه من واتساب

📲 الكود بييجي من واتساب الرسمي نفسه — التطبيق مش بيبعت كود ولا بيخترعه.
• لو إعدادات الـ API الرسمي (التوكن) متعبية في قسم 4️⃣، زرار «اطلب كود التحقق» هيطلب الكود من واتساب الرسمي عبر Cloud API.
• لو التوكن مش متعبّي، الزرار هيفتحلك WhatsApp Manager الرسمي في المتصفح عشان تطلب الكود من هناك بنفسك.
• الرقم غير الموثّق مينفعش يتبعت منه بالوضع الرسمي — لازم يتوثّق الأول. الوضع العادي (wa.me) بيفضل متاح على طول.

لسه مفيش رقم مرسل مضاف — ضيف رقمك الرسمي الأول.
